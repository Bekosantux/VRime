## 未実装の機能

### レーザー方式の入力

グリップ入力に加え、レーザーポインターでキーを指して入力する方式を設ける。日本語・英語のそれぞれについて、使う入力方式（QWERTY / フリック / グリップ）を設定で選ぶ。日本語と英語で別の方式を設定している場合は、言語を切り替えるとその方式のキーボードに変わる。

- レーザーポインター: コントローラーの位置と向きから光線を飛ばし、キーボードとの交点を自前で計算して描画する。SteamVR 標準のレーザーは、ダッシュボードを閉じているときは基本的に使えないためである。
- フリック: 一般的なスマートフォンの12キー配列。キーを指し、トリガーを引いたまま方向へ動かし、離して入力する。方向は、押した位置から指す位置がどの向きにどれだけ動いたかで判定する。手ブレで誤判定しないよう、しきい値を設定で調整できるようにする。英語は12キーの英字配列（ABC / DEF …）。
- QWERTY: キーを指し、トリガーで押す。両手のレーザーを同時に使える。日本語ではローマ字入力とし、ローマ字からかなへの変換はアプリ側で行う（一般的なローマ字表に準拠）。英語ではそのまま英字を入力する。
- 日本語と英語の切り替えは、キーボード上の「言語」キーで行う。
- 候補欄: 候補をレーザーで指してトリガーで選ぶ。文節の切り替えは、候補欄の文節を直接指して行う。
- 表示モード: 頭部固定だと頭の動きでキーがずれて狙えないため、レーザー方式では開いた時点の位置で空間に固定する（空間固定）。頭部固定と空間固定は設定で選べるようにし、グリップ入力の既定は頭部固定とする。
- 作る順序: レーザーポインターと日本語の QWERTY・フリック、次に英語の QWERTY・フリック。

### 設定項目

| 分類 | 項目 |
|---|---|
| 入力方式 | 日本語の方式・英語の方式（QWERTY / フリック / グリップ） |
| コントローラー | SteamVR のバインド設定画面を開く（`IVRInput::OpenBindingUI`） |
| グリップ入力 | 子音パネルの手（右 / 左）、振動の強さ |
| フリック | 方向判定のしきい値 |
| 表示 | 表示モード（頭部固定 / 空間固定） |
| 開閉 | 同時押しとみなす時間差、2回押しの間隔（VRChat で両手で物を持つ動作などとの誤判定を避けるため） |
| 出力 | VRChat へ送るときの通知音、デスクトップへ送った後に Enter を押すか |

## 見直し候補

試用の結果によって変える可能性がある事項。

- 候補欄でスティックを倒し続けたときに、文節・候補を連続で動かすか（現在は 1回倒すごとに 1つ）。
- 振動の Input・Invalid の値（[grip-input.md](spec/grip-input.md#振動)）。Move・OpenClose と違い、実機での調整を経ていない。
- Valve Index のグリップの判定方法。Index のグリップは、静電容量センサーによる握り量（`value`）と感圧センサーによる握る力（`force`）を持つ。握り量で判定する場合、ストラップで固定した指がグリップに触れている間は押下が続くため、「パネルの切り替え」を解除するには指を開ききる必要がある。既定のバインド（`bindings_knuckles.json`）の `button` モードがどちらで判定するかを実機で確かめ、必要なら握る力で判定するモード（`grab` など）と閾値に変える。
