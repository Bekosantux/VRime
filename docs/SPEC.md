## 概要

SteamVR 上で動作する、日本語入力用のキーボードオーバーレイアプリ。主に VRChat のテキストチャットでの利用を想定し、デスクトップのアプリへの入力にも対応する。

- VR 内で、HMD を外さずに日本語の文章を入力・変換・送信できるようにする。
- レーザーポインターを使わない独自の入力方式「グリップ入力」を提供する。

### 対象範囲

- 対象: Windows 10/11 + SteamVR。VRChat（PC版）とデスクトップのアプリへの入力。
- 対象外: Quest 単体版の VRChat、SteamVR を経由しない OpenXR ランタイム（Virtual Desktop の VDXR など）、macOS/Linux、予測変換、VRChat のチャット欄の開閉に連動した自動表示、VRChat の起動だけに連動した自動起動。

## 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11（64bit） |
| VR ランタイム | SteamVR（必須） |
| コントローラー | 動作確認済み: Meta Quest（Air Link / Steam Link / Virtual Desktop で SteamVR 経由）。<br>未確認（既定のバインドは同梱するが、実機での動作を確認していない）: Valve Index、HTC Vive ワンド（トラックパッドをスティック代わりに使う）、Pico、HTC Vive Focus 3、Steam Frame。利用者からの報告を受けて順次確認する。<br>そのほかのコントローラーは、SteamVR のバインド設定画面で割り当てれば使える（[grip-input.md](spec/grip-input.md#コントローラーの割り当て)） |
| VRChat | PC版。VRChat 側で OSC を有効にする（Action Menu → Options → OSC → Enabled） |
| ネットワーク | 変換に必要（Google の API を使うため） |

## 用語

| 用語 | 意味 |
|---|---|
| グリップ入力 | 本アプリの入力方式。グリップボタンを握っている間だけパネルが機能レイヤーに切り替わることに由来する |
| 子音パネル / 母音パネル | グリップ入力で左右の手が担当するパネル。子音パネルで 3×3 のセル（行）を、母音パネルで方向（段）を選ぶ |
| グリップのパネル | 子音パネルと母音パネルの総称 |
| 子音側 / 母音側 | 子音パネル / 母音パネルを担当する手と、そのパネル |
| 子音の手 | 子音側を担当する手（右 / 左）。既定は右手 |
| 入力モード | 子音パネルに並べる文字の種類。かなモード・英字モード・数字モードがある |
| 基本レイヤー / 機能レイヤー | 「パネルの切り替え」を押していない間 / 押している間に、その手のパネルに表示する配置。機能レイヤーは機能キーと、基本レイヤーにない文字を持つ。どちらも入力モードごとにある |
| グリップ・スティック・トリガー | 既定のバインドでそのボタンに割り当てるアクションを指す。グリップは「パネルの切り替え」（開閉の文脈では「展開・収納」）、スティックは「キーの選択」、トリガーは「キーの入力」 |
| 入力バッファ | 送信する前の文字列。確定済みの文字列と、未確定のかなからなる |
| 送信先 | 前面のウィンドウから決まる、文字列を送る相手（VRChat・デスクトップのアプリなど） |

## 非機能要件

| 項目 | 内容 |
|---|---|
| 安全性 | 他のプロセスへのコード注入やメモリの読み取りをしない（VRChat の EAC に配慮） |
| 応答性 | キーやセルの移動は1フレーム以内に表示に反映する。変換は API の応答（約0.3秒）＋描画で表示する |
| 描画負荷 | オーバーレイは表示が変わったときだけ更新する |
| プライバシー | 入力内容を保存・送信しない。例外は変換の際に送る読みだけ（[conversion.md](spec/conversion.md#プライバシーと同意)） |
| 配布 | フォルダーごと置けば動く形式。.NET ランタイムなどの追加のインストールを不要にする |
