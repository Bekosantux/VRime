# 変換

## 変換エンジン

Google CGI API for Japanese Input（https://www.google.co.jp/ime/cgiapi.html）を使う。

- リクエスト: `GET https://www.google.com/transliterate?langpair=ja-Hira|ja&text=<読み>`
  - 読みは UTF-8 で URL エンコードする。API の説明のページは http だが、https でも動作する。
- レスポンス: 文節ごとの候補（JSON）。1文節あたり最大5件。
  ```json
  [["きょうは",["今日は","きょうは","教は","強は","凶は"]],
   ["いいてんき",["いい天気","良い天気","イイ天気","好い天気","いいてんき"]]]
  ```
- 応答時間: 約250〜370ミリ秒（2026-10-03 の実測）。
- 読みに `,` を入れると、文節の区切りを指定できる（例: `きょうは,いいてんき`）。

## プライバシーと同意

- 変換は、設定画面の「個人情報」の「変換に Google API を使用する」（既定はオフ）がオンの間だけ使える。
- オフからオンにするときは、設定画面に注意事項と［同意してオンにする］［キャンセル］を表示し、同意したときだけオンにする。キャンセルではオフのまま閉じる。注意事項の内容:
  - 「変換」を押したとき、**入力中の読み（ひらがな）が Google に送信される**こと
  - 確定済みの文章や送信先（VRChat など）の情報は送信しないこと。1文字入力するごとに送信することもないこと
  - 送信した読みには Google のプライバシーポリシーが適用されること
  - 通信は https で暗号化して行い、入力内容をこのアプリのログやファイルに残さないこと
  - この設定はいつでもオフにできること
- 注意事項を表示している間は、その画面のボタンだけを操作できる。ポインターが設定画面から外れても閉じない。
- オンからオフにするとき、「既定に戻す」で戻すときは確認しない。
- オフの間、「変換」のセルは無効のセルとして表示し、押すと無効の振動を返す（変換の要求を出さない）。かなのまま確定することはできる。

## 候補欄

「変換」を押すと、キーボードの上に候補欄が開く。

### 表示

- 文節を横に並べ、選択中の文節を強調する。選択中の文節の下に、その文節の候補（最大5件）を縦に並べる。各文節の初期選択は1番目の候補。
- 並べた文節が入力欄の幅を超えるときは、選択中の文節が見える位置まで横にずらす。1つの文節・候補が入力欄の幅を超えるときは、収まる長さで切って「…」を付ける。
- 応答を待っている間は、候補欄に「変換中…」だけを表示する。
- 変換に失敗して代わりの候補を出しているとき（[エラー時の扱い](#エラー時の扱い)）は、文節の並びのすぐ上に「変換に失敗しました: <理由>」を表示する。

### 操作

変換中はパネル（子音・母音・機能ページ）への操作を受け付けず、すべて候補欄の操作として扱う。

| 操作 | 動作 |
|---|---|
| 左右どちらかのスティック 左右 | 選択する文節を移動する |
| 左右どちらかのスティック 上下 | 選択中の文節の候補を選ぶ（上 = 前の候補、下 = 次の候補） |
| トリガー | すべての文節を、選んでいる候補で確定する（入力バッファの確定済み文字列になる） |
| グリップ（パネルの切り替え） | 変換を取り消して、未確定のかなに戻す（機能ページは開かない） |

- スティックは1回倒すごとに1つ動かす。倒し続けても連続では動かない。
- 文節・候補の移動は端で止まる（先頭と最後の間で巡回しない）。止まったときは振動を出さない。
- 「変換」を押したときに握っていたグリップは、一度離すまで無視する。離してからもう一度押すと取り消しになる。取り消しは左右どちらのグリップでもよい。
- 開閉の操作は変換中も有効。
- 応答を待っている間は、候補がないためトリガーを受け付けない。グリップで取り消すことはできる。取り消した後に届いた応答は捨てる。

## エラー時の扱い

- タイムアウトは2秒。API が使えないとき（ネットワークの切断、応答なし、エラー）は、候補欄に失敗の理由を表示し、代わりの候補として 1文節の「ひらがなのまま」「カタカナ（アプリ側で変換）」を出す。
