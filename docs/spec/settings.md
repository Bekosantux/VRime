# 設定

SteamVR ダッシュボードにこのアプリのタブ「VRime」を追加し、そこで設定する。同じ設定画面を、デスクトップの設定ウィンドウとしても開ける。

## 設定画面

- ダッシュボードのタブのアイコンは `StreamingAssets/SteamVR/dashboard_icon.png`。SteamVR 標準のレーザーで操作する。
- 画面の左にカテゴリのタブを縦に並べ、選んだカテゴリの項目だけを右に表示する。起動時は先頭のカテゴリを表示する。
- 右下に「既定に戻す」を置き、表示中のカテゴリの項目だけを既定値に戻す。
- 左下（タブの列の下）に「アプリを終了」を置き、確認せずにアプリを終了する（[lifecycle.md](lifecycle.md#終了)）。
- 保存に失敗したときや、設定ファイルを読めなかったときは、画面の下部に通知を出す。

### 操作

- 数値の項目は、項目名・［−］・スライダー・［＋］・現在の値を並べる。［−］［＋］は刻み1つ分ずつ変える。スライダーはドラッグして動かす。
- オン・オフの項目は、項目名・スイッチ・現在の値（オン / オフ）を並べ、行のどこを押しても切り替わる。
- 選択肢の項目は、項目名と現在の値を示すドロップダウンを並べる。ドロップダウンを押すと、その下に選択肢の一覧をほかの行に重ねて開く。選択肢を押すとその値にして一覧を閉じる。一覧を開いている間は選択肢だけを操作でき、選択肢以外の場所を押す・ポインターが画面から離れると、値を変えずに閉じる。
- ボタン・スイッチ・タブは、押したのと同じものの上で離したときに動作する。

### 項目

| カテゴリ | 項目 | 既定 |
|---|---|---|
| 表示 | テーマ（ダーク / ライム） | ライム |
| | 表示位置の5項目（[keyboard.md](keyboard.md#表示位置)） | |
| グリップ入力 | トリガーのしきい値・スティックのしきい値・長押しの時間（[grip-input.md](grip-input.md)） | |
| 外部連携 | 起動時にVRChatにフォーカス（[output.md](output.md#vrchat)） | オン |
| | 入力中の文字をテキストボックスに表示（[output.md](output.md#vrchat)） | オン |
| | 貼り付け成功時に「貼付」キーを戻す（[output.md](output.md#貼り付けモード)） | オン |
| | SteamVRの起動時に自動で起動（[lifecycle.md](lifecycle.md#steamvr-への登録と自動起動)） | オフ |
| 個人情報 | 変換に Google API を使用する。オンにするには注意事項への同意が必要（[conversion.md](conversion.md#プライバシーと同意)） | オフ |

- テーマは、キーボードと設定画面の色を切り替える。デスクトップの設定ウィンドウの余白の色もテーマに従う。
- 「表示」のカテゴリを表示している間だけ（ダッシュボードのタブ・デスクトップの設定ウィンドウのどちらでも）、位置の確認用にキーボードを表示する（[keyboard.md](keyboard.md#steamvr-ダッシュボードとの共存)）。
- 「SteamVRの起動時に自動で起動」の値は SteamVR が持ち、設定ファイルには保存しない。押すとすぐ SteamVR の設定を変える。SteamVR の設定画面で変えた値も、設定画面を表示している間に反映する。エディターでは SteamVR に登録しないため、値の欄に「利用不可」と表示し、押しても変わらない。「既定に戻す」ではオフに戻す。

### 反映と保存

- 変えた値は、キーボードの位置と入力の判定、テーマ、チャットボックスへの入力中の文字の表示、変換を使えるか、貼り付けモードを戻すかにすぐ反映する。「起動時にVRChatにフォーカス」は次回の起動から有効。
- 保存は値が確定したとき（スライダーを離したとき、ボタン・スイッチ・選択肢を押したとき）に行う。
- 保存に失敗しても、アプリは動き続ける（反映済みの値はそのまま使う）。

## デスクトップの設定ウィンドウ

- トレイの「設定を開く」・アイコンの左クリック（[lifecycle.md](lifecycle.md#システムトレイ)）で開く。ビルドだけで、エディターでは開かない。
- 内容と状態（表示しているカテゴリ・開いている同意の画面など）はダッシュボードのタブと共有し、マウスの左ボタンで操作する。
- 最初に開くときは設定画面のテクスチャ（1280×872 ピクセル）と同じ大きさにし、画面の解像度の 8割に収まらなければ縦横比を保って縮める。2回目以降は利用者が変えた大きさを保つ。ウィンドウの縦横比が違うときは、余白を暗い色で埋める。
- ×ボタン・Alt+F4 では終了せず、ウィンドウを隠す。
- ダッシュボードのタブと同時に操作すると、指している対象・ドラッグしているスライダー・押しているボタンを共有するため、互いの操作を中断する。

## 設定ファイル

`%AppData%\VRime\settings.json`。UTF-8 の JSON。

```json
{
  "version": 1,
  "display": { "downMeters": 0.26, "forwardMeters": 0.85, "rightMeters": 0, "tiltDegrees": 17, "widthMeters": 0.45, "theme": "lime" },
  "grip": { "triggerThreshold": 0.7, "stickThreshold": 0.5, "repeatDelaySeconds": 0.5 },
  "vrchat": { "focusOnStartup": true, "showTypingText": true, "resetPasteModeAfterSend": true },
  "privacy": { "useGoogleConversion": false }
}
```

- `theme` は `"dark"` か `"lime"`（大文字・小文字を区別する）。
- 項目が欠けている場合は、その項目だけ既定値を使う。
- JSON として読めない、型が違う、範囲外の値がある、`version` がない・対応していない場合は、ファイルを `settings.invalid-yyyyMMdd-HHmmss.json` に名前を変えて残し、すべて既定値で起動する。設定画面の下部に、その旨と残したファイル名を表示する。
- ファイルの読み書き自体に失敗した場合（権限など）は、起動時は起動の失敗として扱う（[lifecycle.md](lifecycle.md#起動)）。
