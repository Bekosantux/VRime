# グリップ入力

レーザーポインターを使わない独自の入力方式。フリック入力の考え方を踏襲し、子音パネルで行を、母音パネルで段を選ぶ。用語は [SPEC.md](../SPEC.md#用語) を参照。

## 表示のレイアウト

キーボードは 1枚の正方形のテクスチャに描画する。上から次の順に並べる。上の部分は候補欄のための領域で、通常は透明にする。

- 候補欄（[conversion.md](conversion.md#候補欄)）: 変換の応答待ち・変換中だけ表示する。下端を入力欄の直上にそろえて置く（候補が少ないときは上が空く）。
- 入力欄: 確定済みの文字列と、下線付きで色を変えた未確定のかな、カーソル。表示するのは 2行分で、長い入力は、カーソルのある行が見える位置までスクロールする。入力欄の下の状態行に、左から通知・送信先・文字数（[output.md](output.md)）を表示する。通知と送信先の名前は、収まらない分を切り詰めて「…」を付ける。
- パネル: 母音パネルを左、子音パネルを右に置く（子音の手の設定に従い、左右は入れ替わる）。それぞれの上に、いま表示しているレイヤーの役割（母音・子音・機能）を表示し、機能レイヤーを表示している間はその色を変える。中央の上部に、入力モード（かな・英字・数字）と、全角 / 半角・大文字 / 小文字の状態を示すチップを置く。
- 選択中のセルを強調し、無効なセルと空きセル（「・」）は暗く、点灯中のセルは下端にバーを付けて示す。変換中は操作を受け付けないため、パネル全体を暗くする。

### 機能レイヤーのヒント

基本レイヤーを表示しているパネルでは、各セルの右下に、同じ位置の機能レイヤーのキーの頭文字を小さく薄く示す。グリップを握らずに機能レイヤーの配置を確かめられるようにするためである。

- 示すのは機能レイヤーのセルの表示名の先頭の1文字（消去→消、全/半→全、記号→記 など）で、入力モードと全角 / 半角の設定を反映する。機能レイヤーの空きセルの位置には示さない。キーの状態（無効・点灯）は示さない。
- 母音パネルは5方向のセルしか持たないため、四隅（全/半・数字・↑・貼付）にはセルを置かず、ヒントの文字（全・数・↑・貼）だけを置く。
- 「貼付」は、使えない間（[母音側の機能レイヤー](#母音側の機能レイヤー)）は空きセルとして扱うため、ヒントも示さない。
- 機能レイヤーを表示している間、そのパネルにはヒントを示さない。

### 方向のヒント

子音パネルの文字のセルでは、上下左右の辺の中央に、母音パネルをその方向に倒したときに入力される文字を小さく薄く示す（左にい段・上にう段・右にえ段・下にお段。例: 「な」のセルに に・ぬ・ね・の）。母音パネルを見ずに、目的の文字の方向を確かめられるようにするためである。

- 子音側の機能レイヤーの文字のセル（わ・記号・`,`・`-`・`0`・`.`）にも示す。動作のセル（消去・空白・小゛゜）と空きセルには示さない。
- 英字モードの大文字・全角の状態を反映する。未割り当ての方向には示さない。
- 選択中のセルのヒント（機能レイヤーのヒント・方向のヒント）は、選択中の背景の上で読めるよう、選んでいないセルとは別の色で示す。

## 基本の操作

- **子音パネル**（既定は右手）: スティックを倒した方向で、3×3 のセルから1つを選ぶ。倒さない状態が中央のセル。
- **母音パネル**（既定は左手）: 子音パネルで選んだセルの文字を、スティックの方向で選ぶ。中央・左・上・右・下の5方向。
- スティックは、倒した量がしきい値（既定 0.5）以上で方向を決め、しきい値未満で中央に戻る。子音パネルは方向を8つに分ける（1方向あたり45°）。
- トリガーは引いた量（0〜1）で判定する。しきい値（既定 0.7）以上で押したとみなし、押している間はしきい値未満になると離したとみなす。
- 2つのしきい値は設定画面で 5〜95%（5% 刻み）の範囲で変えられる。
- **母音側のトリガー**を引くと、その時点で選ばれている文字を入力する。
- **子音側のトリガー**を引くと、カーソルの直前の1文字を切り替える（[直前の文字の切り替え](#直前の文字の切り替え)）。スティックで選んでいる文字は入力しない。
- 同じフレームで両方のトリガーを引いた場合は、入力してから切り替える。
- 片方の機能レイヤーを表示している間は、左右どちらのトリガーでもセルを実行する（子音側のトリガーでも切り替えにはならない）。両手の機能レイヤーを表示している間は、引いた手のパネルのセルを実行する（[機能レイヤーの共通ルール](#機能レイヤーの共通ルール)）。
- 子音パネルと母音パネルの左右を入れ替えると、トリガーの役割も一緒に入れ替わる。

## 長押し（連続入力）

トリガーを引いたままにすると、長押しの時間（既定 0.5 秒）の後、0.1 秒ごとに同じ入力を繰り返す。長押しの時間は設定画面で 0.20〜1.00 秒（0.05 秒刻み）の範囲で変えられる。

- 繰り返すのは、文字（機能レイヤーの文字を含む）・消去・空白・← / → だけ。直前の文字の切り替え（子音側のトリガー・「小゛゜」）、入力モードや状態の切り替え、変換、確定は、引いたままでも1回だけ実行する。
- 同じフレームで子音側のトリガーも引いて文字を切り替えた場合は、繰り返さない。
- 次のときに繰り返しを止める。止まった後は、トリガーを引き直すまで入力しない。
  - そのトリガーを離した（しきい値未満に戻した）
  - 選択（子音のセル・母音の方向・基本レイヤーと機能レイヤーの切り替え）が変わった
  - 別のトリガーを引いた
  - キーボードを閉じた（ダッシュボードによる一時停止を含む）
- 繰り返しの途中で実行できなくなったとき（消す文字がない、カーソルが端にある、最大長に達した）は、1回だけ振動で知らせて止まる。
- 1フレームで繰り返すのは1回まで。フレームが遅れても、遅れた分をまとめて入力しない。

## 直前の文字の切り替え

カーソルの直前の1文字を、その文字に応じて切り替える。入力モードには依存しない。対象外の文字のときや、文字がないときは、何もせずに振動で知らせる。

- かな: 濁点・半濁点・小書きの順に巡回する（か→が→か、は→ば→ぱ→は、つ→っ→づ→つ、う→ぅ→ゔ→う、あ→ぁ、や→ゃ、わ→ゎ など）。
- 英字（半角・全角）: 大文字と小文字を切り替える（a→A→a、ａ→Ａ）。

## 入力モード

子音パネルに並べる文字は、入力モードによって変わる。

| 入力モード | 入力する文字 | 切り替え方 |
|---|---|---|
| かなモード | ひらがな、句読点 | 言語が日本語のとき |
| 英字モード | アルファベット、数字、一部の記号 | 言語が英語のとき |
| 数字モード | 数字、記号 | 母音側の機能レイヤーの「数字」 |

### かなモード

```
あ  か  さ
た [な] は
ま  や  ら
```

| 子音 | 中央 | 左 | 上 | 右 | 下 |
|---|---|---|---|---|---|
| あ〜ら（や以外） | あ段 | い段 | う段 | え段 | お段 |
| や | や | 「 | ゆ | 」 | よ |

### 英字モード

```
.   A   D
G  [J]  M
P   T   W
```

| 子音 | 中央 | 左 | 上 | 右 | 下 |
|---|---|---|---|---|---|
| `.` | `.` | `/` | `@` | `:` | `1` |
| A | A | B | C | `#` | `2` |
| D | D | E | F | `_` | `3` |
| G | G | H | I | `%` | `4` |
| J | J | K | L | `&` | `5` |
| M | M | N | O | `=` | `6` |
| P | P | Q | R | S | `7` |
| T | T | U | V | `~` | `8` |
| W | W | X | Y | Z | `9` |

- アルファベットは小文字で入力する（表は見やすさのため大文字で書いている）。大文字は、母音側の機能レイヤーの「↑」で入力するか、子音側のトリガーで直前の文字を切り替えて入力する。
- 下に倒すと、そのセルの位置に対応する数字（1〜9）になる。

### 数字モード

```
1   2   3
4  [5]  6
7   8   9
```

- 各セルの中央はその数字。中央以外の方向は未割り当て（[ROADMAP.md](../ROADMAP.md#未決事項) の U-12）。
- 0 と主な記号は、子音側の機能レイヤーの中段で入力する。
- 数字モードを解除すると、その前の入力モード（かな / 英字）に戻る。

## 子音側の機能レイヤー

子音側の手の「パネルの切り替え」を**押している間**、子音パネルが機能レイヤーに切り替わる（離すと基本レイヤーに戻る）。上段と下段はすべての入力モードで共通で、中段の3つのセルは入力モードによって変わる。

```
・     ・      消去
(左)  [(中央)]  (右)
・     ・      空白
```

「・」は何も割り当てない。中央のセルはスティックを倒さない状態で選ばれるため、グリップを握ったままトリガーを引くと、かなモードでは「わ」、数字モードでは「0」を入力する（英字モードでは何も起きない）。

| 入力モード | 左 | 中央 | 右 |
|---|---|---|---|
| かなモード | 小゛゜ | わ | 記号 |
| 英字モード | ・ | ・ | `,` |
| 数字モード | `-` | `0` | `.` |

中段の3つのセルのうち、文字のセルは母音パネルで文字を選ぶ。

| セル | 中央 | 左 | 上 | 右 | 下 |
|---|---|---|---|---|---|
| わ（かな） | わ | を | ん | ー | 〜 |
| 記号（かな） | 、 | 。 | ？ | ！ | … |
| `,`（英字） | `,` | `.` | `?` | `!` | `'` |
| `-`（数字） | `-` | `+` | `*` | `/` | `~` |
| `0`（数字） | `0` | `(` | `=` | `)` | `&` |
| `.`（数字） | `.` | `,` | `:` | `;` | `%` |

| キー | 動作 |
|---|---|
| 消去 | カーソルの直前の1文字を消す |
| 空白 | スペースを入れる。かなモードでは全角、英字モード・数字モードでは「全/半」に従う。未確定のかながあれば、先にそのまま確定してから空白を入れる |
| 小゛゜ | 直前の文字の切り替え。子音側のトリガーと同じ動作 |

## 母音側の機能レイヤー

母音側の手の「パネルの切り替え」を**押している間**、母音パネルが 3×3 の機能レイヤーに切り替わる（離すと基本レイヤーに戻る）。

```
全/半   言語   数字
←     [確定]   →
↑      変換   貼付
```

中央のセルはスティックを倒さない状態で選ばれるため、母音側のグリップを握ったままトリガーを引くと「確定」を実行する。

| キー | 動作 |
|---|---|
| 全/半 | 英字・数字・記号を全角で入れるか半角で入れるかを切り替える。英字モードと数字モードでのみ有効。既定は半角 |
| 数字 | 数字モードにする。数字モードで押すと、その前の入力モードに戻る |
| ← / → | カーソルを移動する |
| ↑ | 大文字入力のオン / オフを切り替える（もう一度押すまで切り替わったまま）。英字モードでのみ有効。オンの間はキーを点灯させる |
| 言語 | 日本語と英語を切り替える。数字モードのときは、数字モードを解除してから切り替える |
| 変換 | 未確定のかなを変換する（[conversion.md](conversion.md)） |
| 確定 | 未確定のかながあれば確定し、なければ送信する。入力バッファが空なら送信先の表示を消す（[output.md](output.md#入力バッファ)） |
| 貼付 | 貼り付けモード（[output.md](output.md#貼り付けモード)）のオン / オフを切り替える。オンの間はキーを点灯させる |

「全/半」と「↑」は、無効な入力モードでは灰色で表示し、トリガーを引いても何もしない。

「貼付」は、前面のウィンドウが VRChat の間だけ使える。それ以外の間は空きセルと同じく「・」を表示し、トリガーを引いても何もしない（振動もしない）。

## 機能レイヤーの共通ルール

- 文字のセル（わ・記号・`,`・`-`・`0`・`.`）以外の機能キーは、トリガーだけで実行する。片方の機能レイヤーを表示している間は、左右どちらのトリガーでもよい。
- 両手の機能レイヤーを同時に表示している間は、子音側のトリガーで子音側の機能レイヤーのセルを、母音側のトリガーで母音側の機能レイヤーのセルを実行する。
  - 子音側の機能レイヤーの文字のセルは、母音パネルで文字を選べないため無効にする（暗く表示し、トリガーを引くと無効の振動で知らせる）。
  - 同じフレームで両方のトリガーを引いた場合は、子音側、母音側の順に実行し、連続入力はしない。
- 英字モード・数字モードで入力した文字は、確定済みの文字列に直接入る。未確定のかながあれば、先に変換せずに確定する。
- かなモードで入力した文字は、わ・記号（、。？！…〜 を含む）も含めてすべて未確定のかなに入る。
- 次の操作は、何もせずに無効の振動で知らせる。
  - 未確定のかながないときの「変換」
  - 未確定のかなも確定済みの文字もなく、送信先の表示を消せないときの「確定」（[output.md](output.md#入力バッファ)）
  - カーソルが端にあるときの ← / →
  - 消す文字がないときの「消去」

## 振動

操作の区切りでコントローラーを短く振動させる。値は種類ごとに決める。

| 種類 | 長さ | 周波数 | 強さ | 用途 |
|---|---|---|---|---|
| Move | 0.01秒 | 160Hz | 0.6 | セル・候補の移動 |
| OpenClose | 0.08秒 | 160Hz | 0.6 | 開閉 |
| Input | 0.03秒 | 160Hz | 0.8 | 文字の入力・確定など。Move より強く長い |
| Invalid | 0.12秒 | 60Hz | 0.8 | 無効な操作。低い周波数で長めにして区別する |

## コントローラーの割り当て

- ボタンの割り当ては、SteamVR のコントローラーバインド機能を使う。利用者は SteamVR のバインド設定画面から割り当てを変えられる。
- アクションは物理的なボタンではなく役割ごとに、左右の手について定義する。

  | アクション | 型 | 役割 | 既定の割り当て |
  |---|---|---|---|
  | 展開・収納（`openclose_left` / `_right`） | boolean | 両手で2回続けて同時押しすると開閉する | グリップ |
  | パネルの切り替え（`panel_left` / `_right`） | boolean | 押している間、その手のパネルを機能レイヤーにする。変換中は取り消し | グリップ |
  | キーの選択（`select_left` / `_right`） | vector2 | セル・方向の選択。変換中は文節・候補の移動 | スティック（Vive ワンドはトラックパッド） |
  | キーの入力（`press_left` / `_right`） | vector1 | セルの入力・実行。変換中は確定 | トリガーの引き量（`pull`） |
  | 振動（`haptic_left` / `_right`） | vibration | 操作の区切りの振動 | 各手の振動 |

- 入力のアクションはすべて必須（`mandatory`）とする。割り当てが欠けていると、SteamVR のバインド設定画面に警告が出る。
- 既定のバインドではグリップを「展開・収納」と「パネルの切り替え」の両方に割り当てる。どちらかを別のボタンに移すと、たとえば開閉だけを別のボタンで行える。左右の「展開・収納」を同じボタンに割り当てると、そのボタンを2回続けて押すだけで開閉する（左右が同時に押されるため）。
- 既定のバインドは Valve Index（`knuckles`）、Meta Quest（`oculus_touch`）、HTC Vive ワンド（`vive_controller`）、Pico（`pico_controller`）、HTC Vive Focus 3（`vive_focus3_controller`）、Steam Frame（`frame_controller`）用を同梱する。
- アクションの表示名は日本語（`ja_JP`）と英語（`en_US`）を用意する。
