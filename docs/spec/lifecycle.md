# 起動・常駐・終了

本書の「ビルドだけ」の動作は、エディターでの再生では行わない。

## 起動

- 本アプリのプロセスは同時に 1つだけにする。起動済みのプロセスがあるときに起動すると、何も表示せずに終了する（ビルドだけ）。
- 起動の処理では、起動済みの SteamVR に接続する。SteamVR が起動していない、HMD が見つからないなど、接続に失敗したときは起動の失敗として扱う。
- Unity はスクリプトが動く前にウィンドウを作るため、起動の処理の間は小さなウィンドウ（640×480）が表示される。スプラッシュ画面は表示しない。起動の処理を終えたら、ウィンドウを隠し、タスクバーと Alt+Tab の一覧からも外す（ビルドだけ）。
- 起動の処理に失敗したときは、メッセージボックスで次の内容を示し、閉じたら終了する（ビルドだけ。エディターでは例外を送出する）。
  - エラーのメッセージとスタックトレース
  - 頻繁に発生する場合は開発者に問い合わせるよう求める文
  - Ctrl+C でエラー文をコピーできること
- 起動時に VRChat を前面にする（[output.md](output.md#vrchat)）。

## SteamVR への登録と自動起動

SteamVR にアプリとして登録し、SteamVR と同時に自動で起動できるようにする。自動で起動するかは、設定画面の「SteamVRの起動時に自動で起動」で切り替える。

- 登録はビルドの起動のたびに行う。マニフェストは `%AppData%\VRime\VRime.vrmanifest` に書き、exe・アクションマニフェスト・アイコン（`StreamingAssets/SteamVR/dashboard_icon.png`）の絶対パスを含める。フォルダーを移動しても、次に起動したときに登録が更新される。複数の場所に置いた VRime を起動すると、最後に起動したものが登録される。
- app key は `vrime.keyboard`。自動で起動するかどうかと、利用者が変えたコントローラーのバインドは、SteamVR がこのキーに結び付けて保存する。
- ダッシュボードのオーバーレイとして登録する。SteamVR の設定（起動 / 終了 → 起動時のオーバーレイアプリ）にも表示され、そこで切り替えた値と設定画面の値は同じものになる。
- 初めて登録したときは、自動で起動しない。
- VRChat を VR で起動すると SteamVR も起動するため、この設定をオンにすれば VRChat の起動に合わせて本アプリも起動する。
- エディターでは登録しない（Unity のエディター自体が登録されるため）。

## システムトレイ

起動後は画面に何も出さず、システムトレイにアイコンを置く（ビルドだけ）。

- アイコンは `StreamingAssets/Windows/tray_icon.ico`、ツールチップは「VRime」。
- 右クリック（キーボードではメニューキー・Shift+F10）でメニューを開く。
  - 「設定を開く」: 太字の既定の項目。デスクトップの設定ウィンドウ（[settings.md](settings.md#デスクトップの設定ウィンドウ)）を開く。
  - 「終了」: 確認せずに終了する。
- 左クリック・Space・Enter は「設定を開く」と同じ。
- メニューを開いている間も、キーボードは動き続ける。
- エクスプローラーが再起動したら、アイコンを再表示する。

## 終了

- 次のどれかで終了する。いずれも同じ処理で終了する。
  - SteamVR の終了
  - 設定画面の「アプリを終了」
  - トレイの「終了」
- 終了時は、チャットボックスに表示している入力中の文字を消し、クリップボードの戻す前の内容を戻す（[output.md](output.md)）。
