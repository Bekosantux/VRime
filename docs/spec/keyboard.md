# キーボードの表示と開閉

用語は [SPEC.md](../SPEC.md#用語) を参照。

## 表示位置

- 開いた時点で、視界の下部（HMD 基準で下 約0.26m・前 約0.85m・こちら向きに約17°傾ける）に表示し、頭の動きに追従する（頭部固定）。
- 位置の基準は、テクスチャの中心ではなく**キーボードの本体（盤面）の中心**とする。テクスチャの上部には候補欄のための透明な領域があり、テクスチャの中心を基準にすると盤面が下にずれるためである。
- 位置・傾き・大きさは設定画面（[settings.md](settings.md)）で調整できる。

  | 項目 | 範囲 | 刻み | 既定 |
  |---|---|---|---|
  | 下への距離（盤面の中心） | 0〜60cm | 1cm | 26cm |
  | 前への距離（盤面の中心） | 30〜150cm | 1cm | 85cm |
  | 左右の位置（盤面の中心。右が正） | 左 50cm〜右 50cm | 1cm | 中央 |
  | 傾き（0° で HMD の正面に垂直に立つ） | 0〜60° | 1° | 17° |
  | 幅（テクスチャ全体） | 25〜90cm | 1cm | 45cm |

## 開閉

- **両手の「展開・収納」のボタン（既定はグリップ）を2回続けて同時押し**すると開く。開いているときに同じ操作で閉じる。
  - 左右のボタンを押した時刻の差が **0.20秒以内** なら同時押しとみなす。
  - 同時押しを **0.60秒以内** に2回行うと開閉する。
  - 開閉したときに両手を振動させる。
- 閉じても入力バッファは保持し、開き直すと続きから入力できる。変換中（応答待ちを含む）に閉じたら変換を取り消し、未確定のかなに戻す。
- 開いた時点で押していた「パネルの切り替え」のボタン（既定はグリップ）は、一度離すまで押されていないものとして扱う。開閉の同時押しの直後に機能ページが開かないようにするためである。

## コントローラー入力の横取り

- キーボードを開いている間は、VRChat などのゲームにコントローラー入力を渡さない（スティックを倒しても歩かない）。
- 閉じている間は、ゲームと入力を共有し、開閉の操作だけを監視する。

## SteamVR ダッシュボードとの共存

- ダッシュボードの表示中は、SteamVR が入力をダッシュボードに回すため、キーボードを一時的に閉じる。ダッシュボードが閉じ、入力がアプリへ戻ったら自動で再開する。
- ダッシュボードでこのアプリの設定タブの「表示」のカテゴリを表示している間は、キーボードを閉じたまま、オーバーレイだけを表示する。設定画面で変えた位置・大きさをその場で確かめるためである。ほかのカテゴリでは表示しない。このとき、入力は占有しない。
